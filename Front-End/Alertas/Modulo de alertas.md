Funcionalidad
El flujo comienza cuando el sistema detecta que el stock de un producto (como la "Leche Deslactosada" o el "Tonayán") cae por debajo
del límite configurado en el registro.
La interfaz permite al usuario evaluar visualmente qué tan crítica es la falta (ej. stock en "0") y decidir la acción a tomar 
directamente desde la tabla.
El flujo finaliza cuando el usuario procesa las alertas seleccionadas para generar una orden de compra. Esto sirve de puente directo
hacia el módulo de "Registro de Entrada", cerrando la brecha entre la escasez y el resurtido de mercancía.
Al mantener este flujo activo, la interfaz asegura que los productos de "Alta Rotación" nunca dejen de estar disponibles para la 
venta final.
