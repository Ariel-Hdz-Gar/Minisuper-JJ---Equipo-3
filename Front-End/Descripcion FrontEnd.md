El FrontEnd del sistema para el proyecto Minisuper-JJ fue desarrollado en Visual Studio Code usando los lenguajes de HTML, Java Script y CSS y esta siendo almacenado en la carpeta Front-End

Aquí se dividen las interfaces por los casos de uso establecidos en las primeras etapas del proyecto, las cuales son:
-Iniciar Sesión (Dueno, InicioSesin, Empleado)
-Reporte(Reporte)
-Seguridad(Seguridad)
-Caja(Gestion)
-Inventario(Registro_Entrada, Registro_producto, Registro_venta)
-Alertas(Alertas)
-Gestionar Adeudos(Adeudos)

Ademas se adjuntaron capturas de pantalla de cada interfaz en la carpeta "Capturas de la Interfaz" y se creo una caprta llamada "Commits del Front-End" para evidenciar el trabajo en equipo
