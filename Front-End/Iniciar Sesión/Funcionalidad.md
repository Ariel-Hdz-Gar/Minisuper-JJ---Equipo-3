La interfaz captura el usuario y la contraseña para compararlos con base de datos local.
Si los datos coinciden, el sistema redirige automáticamente al usuario según su nivel de privilegio: el usuario "Test1" es enviado 
al panel de Dueño (Dueno.html), mientras que "Test2" es dirigido al de Empleado (Empleado.html).
En caso de fallo, la interfaz utiliza un script para mostrar un mensaje de error sin recargar la página, mejorando la experiencia
de usuario.
Permite al dueño navegar rápidamente entre las áreas críticas del negocio: Reportes, Gestión y Seguridad.
Cada elemento de la cuadrícula actúa como un enlace directo que carga los submódulos correspondientes del sistema administrativo.
La interfaz facilita el flujo de trabajo operativo permitiendo al empleado registrar entradas de mercancía, nuevos productos y ventas
finales de manera secuencial.
