MariaDB 11.8.3
Para instalar MariaDB en Windows 11 mediante el instalador oficial MSI:

Descarga el paquete de instalación oficial .msi correspondiente a la versión 11.8.3 desde el sitio web de MariaDB.

Ejecuta el instalador y sigue el asistente (Next).

Acepta los términos de la licencia y selecciona la ruta de instalación.

Define la contraseña del usuario root y activa la opción para permitir conexiones remotas si tu entorno lo requiere.

Asegúrate de marcar la casilla Install as Service para que el servicio de base de datos se ejecute en segundo plano con el nombre por defecto (MariaDB).

Haz clic en Install y finaliza la instalación.
